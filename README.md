🔐 Security Toolkit – Comprehensive Cybersecurity GUI Application

A powerful Python-based GUI Security Toolkit designed for learning, practicing, and demonstrating core concepts of cryptography, password security, file protection, and cyber forensics.

This project integrates multiple security tools into a single modular, scalable desktop application built with Tkinter.

🚀 Features
🔐 Encryption & Decryption
AES-256 Encryption
RSA Encryption (Basic + Advanced)
SHA-256 Hash Generator & Verifier
Classical Ciphers:
Caesar Cipher
Vigenère Cipher
Playfair Cipher
Hill Cipher (2x2)
Affine Cipher
Autokey Cipher
Multiplicative Cipher
Encoding Tools:
Base64 Encoder/Decoder
Morse Code Translator
Transposition Techniques:
Columnar Cipher
Rail Fence Cipher
Key Transposition Cipher
🔑 Password & Authentication
Strong Password Generator
Password Strength Checker
Secure Password Manager (Local Storage)
📁 File & Data Security
File Encryption & Decryption
Steganography (Hide Text in Images)
File Hash Checker
Secure File Shredder
🔍 Cyber Forensics & Analysis
File Metadata Extractor
Image EXIF Viewer
File Integrity Checker
Log File Analyzer
Email Header Analyzer
🖥️ GUI Highlights
Clean and modern UI using Tkinter + ttk
Tab-based tool navigation

📦 Installation
1. Clone the Repository
git clone https://github.com/baladitya142857/Cybersecurity-Toolkit
cd security-toolkit
2. Install Dependencies
pip install cryptography pillow
3. Run the Application
python Cyber_Sec_main.py
